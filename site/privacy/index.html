Lectern Privacy Policy

Effective October 27, 2026

Lectern is a browser extension that assists reading: it tracks your progress and focus time on articles, translates and explains text you select, and turns looked-up words into review cards. Model requests go directly to your chosen provider. If you enable device sync, the operator of your configured sync server can access the data sent to it.

Data stored on your device

The following is kept in the browser's local storage unless you use the model or sync features described below:

  • Web pages identified as articles: URL, title, body text, and your reading progress and focus time on them.
  • Text you looked up, the model's translations and explanations, and the review cards and review history built from them.
  • Your settings, including the API key for the model service. The key is never exposed to web pages and is never included in exported files.
  • Diagnostic logs (recent errors and translation timings) and click counts for home-page buttons.

Data sent to the model service

Lectern uses the API key you provide to call, directly, the model service you choose in settings (for example OpenAI, Anthropic, MiniMax, DeepSeek, or an address you enter yourself). There is no preset provider, and requests do not pass through any server run by the developer. The settings page lists the items below, and nothing is sent until you click "Agree and start" there; nothing is sent without an API key either. You can withdraw consent in settings at any time. What is sent:

  • Article detection (automatic): when you open a web page, Lectern sends only its HTTP(S) URL to the model, after removing usernames, passwords, query strings and fragments. No page title or text is sent for detection. The remaining domain and path may still contain sensitive information. Pages on sites you add to the "article blocklist" in settings are not sent. If the URL is insufficient to decide, the page is not tracked; Lectern does not send content as a fallback.
  • AI filtering of saved records: only the same cleaned URLs are sent to the model. Saved article text is not read and original pages are not fetched for classification. Classification failure diagnostics also use only the cleaned URL.
  • Selection translation (when you select text): the selected text, its surrounding paragraph and the article title. Active only on sites in your translation allowlist, or after you enable it for the current page.
  • Screenshot translation (when you draw a region): text recognition runs on your device and the screenshot is not uploaded; the recognized text is sent to the model.
  • Editing lists in plain language (when you press send): your message, the last few messages, both lists, and the current page URL.
  • Other model features: explaining words, follow-up questions about a passage, generating an article review (automatically at the reading threshold when enabled), asking the model to suggest blocklist rules, and vocabulary chat with selected words, their source context and recent messages. What is sent is the text involved in that action: the relevant passage or article text, its title and URL.

How the model service handles this data is governed by that provider's own privacy policy.

Data sent to a sync server (optional)

Device sync is off by default. Only after you configure and enable a server connection does Lectern send the data listed under "Data stored on your device" (except the API key) to that server, to merge it across your devices. This includes reading records, translations, review data, synced preferences, diagnostic logs and daily button counts. API keys, local EPUB books and vocabulary chat history are not synced. Use a server whose operator you trust.

What we do not do

  • We do not sell or transfer your data to third parties.
  • We do not use data for advertising, creditworthiness, or any purpose unrelated to assisting reading.
  • Lectern includes no third-party analytics service. Daily button counts and diagnostic logs are uploaded only when you enable sync, as described above.

Deleting data

"Clear this device's records" in settings deletes local reading records and cards; uninstalling the extension deletes everything it stored in the browser. Data on a sync server must be deleted on that server.

Contact

Questions: open an issue in the GitHub repository. The effective date on this page is updated when the policy changes.
